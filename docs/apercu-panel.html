Installation et aide
  1. Installe le connecteur ShortcutToggle dans Vencord et active-le dans Discord.
  2. Installe Discord Shortcuts dans Stream Deck, puis sélectionne son bouton.

Vencord est nécessaire. Le guide GitHub explique chaque étape.

Sur OFF, seules les actions des raccourcis cochés sont suspendues. Leurs touches restent disponibles pour écrire et jouer. Discord redémarre sur ON.

Pour ajouter un raccourci : Discord → Paramètres → Raccourcis clavier. La liste suit tes modifications automatiquement.
